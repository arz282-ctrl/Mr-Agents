# 🚀 Manus-Ready Skills — Import Guide

**276 skills** repackaged. Every ZIP has `SKILL.md` at the root. ✅

## How to Import into Manus

### Method 1: Upload ZIP (Recommended)

1. Open Manus → **Skills** or **My Skills** → **Import**
2. Click the **Upload** tab (file/arrow icon)
3. Select ONE `.zip` file from `manus-ready/zips/`
4. Click **Import** — should succeed with no errors
5. **Enable** the skill for your agent
6. Repeat for each skill you want

### Method 2: GitHub Single-Skill Repo

1. Create a new GitHub repo
2. Unzip one `.zip` into the repo root (so `SKILL.md` is at root)
3. Push to GitHub
4. In Manus → Import → GitHub tab → paste the repo URL → Import

## ⚠️ Important

- Import **ONE skill at a time** — not the whole collection
- Some skills need connectors (GitHub, Shopify, Google, etc.)
- Start with 5-10 essential skills
